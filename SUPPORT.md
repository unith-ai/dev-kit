# Support

## Getting help

| Topic | Contact |
|---|---|
| Technical questions about this kit or the UNITH platform | [support@unith.ai](mailto:support@unith.ai) |
| Projects, pilots, pricing, and concurrency sizing | [sales@unith.ai](mailto:sales@unith.ai) |
| Security vulnerabilities | Follow [`SECURITY.md`](SECURITY.md) — never report these publicly. |

Before reaching out, check the
[Troubleshooting](README.md#troubleshooting) section of the README and the
official documentation at [docs.unith.ai](https://docs.unith.ai).

## Reporting a bug in this kit

If something in this kit does not work as documented, open an issue using the
**Bug report** form. Please include:

- The kit version (release tag) or commit you are using.
- Your operating system, Node.js version, and browser.
- The steps you followed, what you expected, and what happened.
- Relevant console output, with all credentials removed.

**Never post secret keys, bearer tokens, API keys, webhook shared keys, or
customer data in an issue.** Issues may become publicly visible.
